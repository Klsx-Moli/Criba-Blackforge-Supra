# ASTRA COVERAGE MATRIX

This matrix separates the **normative status** in `governance/ASTRA_CANON.yaml`
from the strength of current enforcement.

The previous matrix rendered every mapped contract as `LOCAL PASS`. That was
too strong: a mapped file or passing sentinel does not prove the whole runtime
contract. This branch therefore uses the following enforcement vocabulary:

- `ENFORCED`: a behavioral sentinel exercises the material contract.
- `PARTIAL`: meaningful enforcement exists, but material scope remains open.
- `LIMITATION_GUARD`: the implementation prevents an overclaim but does not
  implement the stronger scientific capability.
- `DOCUMENTATION_ONLY`: normative/documentary guard; no runtime capability is claimed.
- `RESEARCH_ONLY`: intentionally not promoted.
- `CONTRACT_ONLY`: future contract recorded; runtime intentionally absent.
