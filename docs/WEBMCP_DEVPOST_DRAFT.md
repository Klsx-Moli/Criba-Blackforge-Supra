## TITLE
**SUPRA WebMCP: Causal Innovation Workbench & Protocol Bridge**

## TAGLINE
Decentralized in-browser Model Context Protocol (WebMCP) bridge connecting LLMs directly to high-dimensional causal compilation and sandbox verification.

## DESCRIPTION

### What it does
SUPRA WebMCP embeds a native JSON-RPC 2.0 Model Context Protocol server directly within a modern browser workbench, exposing:
* **Tools:** `supra_execute_golden_path`, `supra_fuzz_sandbox`, `supra_export_dossier`.
* **Resources:** `criba://catalog/causal-axes`, `blackforge://policy/safety-matrix`, `supra://runtime/active-projects`.
* **Prompts:** `prompt_unchained_disruption`, `prompt_sovereign_gate_review`.

### How it works
Any WebMCP-compatible browser agent or local assistant can query, inspect, and invoke SUPRA's causal compiler and micro-sandbox directly over standard JSON-RPC without custom bespoke wrappers.

### Technologies
WebMCP Protocol (JSON-RPC 2.0), Vanilla JavaScript ES6, FastAPI, Python 3.12, Docker, Google Cloud Run.
